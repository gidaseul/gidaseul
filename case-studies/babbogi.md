# 밥보기 — 섭취 기반 영양소 관리 앱

> 숭실대학교 "소프트웨어프로젝트" 수업 팀 프로젝트 · 2024.04–2024.08 · 2024 소프트웨어공모전 은상
> 4인 팀(프론트엔드 1인, 백엔드 2인 포함 본인, 기획 1인) · [클라이언트 저장소](https://github.com/gidaseul/babbogi) · [서버 저장소](https://github.com/BabBogi/BabBogi-backend)

## Problem

사용자가 자신의 건강 정보와 하루 식사를 직접 계산해 적정 영양소 섭취량과 비교하는 일은 번거롭고 꾸준히 하기 어렵습니다. 팀은 이 반복적인 계산과 기록 과정을 앱이 대신하도록 만드는 것을 목표로 했습니다.

## My Role

4인 팀에서 **백엔드/서버 연동 로직**을 담당했습니다. 프론트엔드(Android/Jetpack Compose UI)는 다른 팀원이 구현했으며, 본인은 클라이언트가 호출하는 API 연동, 서버와의 데이터 송수신 로직, 섭취 기록·영양소 계산과 관련된 서버 측 처리를 맡았습니다.

## Approach

- 사용자의 건강 정보(키·체중·활동량 등)를 기반으로 하루 적정 섭취량을 계산하는 로직을 서버와 연동
- 사용자가 입력한 식사 데이터를 서버에 저장하고, 오늘의 누적 영양 정보를 조회하는 API 흐름 구성
- 권장 섭취량 대비 초과·부족 항목을 판단해 푸시 알림 트리거 조건과 연동되는 데이터 처리
- 클라이언트(Jetpack Compose)와 서버 간 요청/응답 스키마를 팀원과 협의해 정의

## Result

팀은 2024학년도 숭실대학교 소프트웨어공모전에서 **은상**을 수상했습니다. 앱은 식사 입력, 오늘의 영양 정보 조회, 권장 섭취량 초과 시 알림 기능을 실제로 동작하는 형태로 완성했습니다.

## Evidence

- [클라이언트 저장소](https://github.com/gidaseul/babbogi) — Android/Jetpack Compose 앱
- [서버 저장소](https://github.com/BabBogi/BabBogi-backend) — 백엔드 API
- 공모전 수상 자료(비공개 원본, 요청 시 제공 가능)

## Limitations

- 클라이언트 저장소는 팀원(CHOYUNSIG)의 계정을 기준으로 관리되어, 본인 커밋 기록은 서버 저장소 및 팀 협업 히스토리에서 확인할 수 있습니다.
- 사용자 수, 실사용 리텐션 등 정량적인 서비스 지표는 수집하지 않았으므로 성과로 표기하지 않습니다.
